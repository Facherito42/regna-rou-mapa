# Mapa de estaciones REGNA-ROU

Mapa interactivo de las 31 estaciones GNSS de la Red Geodésica Nacional Activa de Uruguay (REGNA-ROU).

Al tocar una estación se ve:

- localidad, departamento y ubicación;
- modelo de receptor y de antena, con foto de cada uno;
- constelaciones que rastrea (GPS, GLONASS, GALILEO, BEIDOU).

La estación antártica UYBA (Base Científica Antártica Artigas) aparece en un recuadro aparte. Las estaciones se pueden filtrar por fabricante del receptor. Cada estación tiene su propio link, agregando el código al final de la dirección, por ejemplo `#UYSA`.

## Ver el mapa

Publicado con GitHub Pages: https://facherito42.github.io/regna-rou-mapa/

También se puede abrir `index.html` directamente en el navegador. Es un único archivo, sin dependencias: las fotos están incluidas dentro del HTML.

## Datos

- **Estaciones:** planilla REGNA-ROU actualizada al 16/11/2026 (coordenadas geodésicas, receptor, antena, ubicación y constelaciones).
- **Límites departamentales y costa:** [Natural Earth](https://www.naturalearthdata.com/), escala 1:10m, de dominio público. Están simplificados para el mapa.
